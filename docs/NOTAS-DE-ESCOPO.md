# Escopo e limites da demonstração

Este repositório documenta a experiência de Sarah Belchior no **Hackathon VINT + INBEC 2026**, desenvolvido em colaboração com a VINT_GLOBAL. **Não é uma pesquisa científica**.

A implementação pública em `demo/` é uma **demonstração didática independente, criada para o portfólio**, a partir dos critérios e pesos descritos no relatório do hackathon. Não é o código-fonte desenvolvido originalmente pela equipe, não é uma cópia do produto, não usa informações de SGD/iHiring e não reproduz refinamento por IA. Os perfis foram inventados para ilustrar um fluxo de triagem e classificação.

O relatório de referência descreve um ranking de skills (40%), disponibilidade (25%), histórico (20%) e aderência (15%). Nesta demonstração, histórico e aderência são pontuações fictícias; disponibilidade é calculada como a menor disponibilidade nos meses solicitados. As regras são apenas ilustrativas, não validadas e não devem ser usadas para decisões reais de recrutamento.

A experiência da autora foi registrada no projeto como **Gestão**. A publicação não atribui a Sarah autoria individual de todo o software do hackathon. Não contém dados internos, nomes de pessoas participantes, currículos, credenciais, marcas gráficas da empresa ou código proprietário.

## Restrições e responsabilidade

- Decisões de alocação e contratação exigem revisão humana, transparência e avaliação de vieses.
- Não se deve interpretar pontuação fictícia como capacidade profissional real.
- Indicadores citados no relatório do projeto são alegações apresentadas pelo material de demonstração, não uma auditoria independente.
- A versão de portfólio pode ser executada localmente abrindo `demo/index.html` no navegador; não requer rede, cadastro ou API.
